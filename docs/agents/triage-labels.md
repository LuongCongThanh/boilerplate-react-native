# Triage Labels

Các skills dùng 5 vai trò triage chuẩn. File này ánh xạ các vai trò đó sang nhãn thực tế trong issue tracker của repo.

| Label trong skills | Label trong repo      | Ý nghĩa                                          |
| ------------------ | --------------------- | ------------------------------------------------ |
| `needs-triage`     | `needs-triage`        | Maintainer cần đánh giá issue này               |
| `needs-info`       | `needs-info`          | Đang chờ người báo cáo cung cấp thêm thông tin  |
| `ready-for-agent`  | `ready-for-agent`     | Đã đặc tả đầy đủ, agent có thể xử lý tự động   |
| `ready-for-human`  | `ready-for-human`     | Cần con người triển khai                         |
| `wontfix`          | `wontfix`             | Sẽ không được xử lý                              |

Khi skill đề cập đến một vai trò (ví dụ "áp dụng nhãn AFK-ready"), dùng chuỗi nhãn tương ứng trong bảng này.

Chỉnh cột bên phải nếu repo dùng tên nhãn khác.
